# Throne Organ Foundation

Status: `CANDIDATE_ORGAN_FOUNDATION`

Throne is the IMPERIUM organ candidate for local git and admission truth. It is not a public service, not a GitHub replacement service, and not Custodes. Its first duty is to prove local git facts and export reviewable evidence bundles when remote web URLs are unavailable or misleading.

## Owned Scope

- Local git truth storage and commit object verification.
- Commit index records.
- Task-to-commit grouping.
- Admission truth records.
- Commit evidence bundle export for Logos-Prime, Inquisition, and Speculum.
- Local SSH-only operator commands for evidence collection.

## Boundary

Throne does not override Doctrinarium law, Officio language and role routing, Astronomicon task registration, Administratum continuity truth, Mechanicus validation, or Inquisition fake-green checks. Future Custodes will own strict admission judgment; this folder only defines the handoff.

## Local Truth Rule

GitHub commit URLs are useful presentation links, but they are optional evidence. If a GitHub URL returns 404 while the local repository proves a commit object by exact SHA and exports a complete evidence bundle, Throne treats the local git object and bundle as the authoritative review source.

## Current Task Limit

This task creates the foundation, contracts, schemas, receipts, and read-only prototype tools. It does not provision the future laptop runtime and does not mutate PC or laptop state.
