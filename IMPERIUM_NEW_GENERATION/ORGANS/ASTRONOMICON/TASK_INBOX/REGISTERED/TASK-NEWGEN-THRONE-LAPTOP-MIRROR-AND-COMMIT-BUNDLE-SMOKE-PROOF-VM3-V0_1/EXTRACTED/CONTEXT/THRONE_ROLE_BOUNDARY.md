# THRONE ROLE BOUNDARY

Throne owns:
- local git/admission truth;
- commit index;
- commit and task grouping;
- evidence bundles;
- runtime/review artifact vault;
- SSH-only local access doctrine.

Throne does not yet own:
- final Custodes admission verdicts;
- public web serving;
- IDE execution;
- WARP runtime;
- Codex CLI bridge.

Throne stores the seal. Custodes later decides who may receive the seal.
