# Matrix Requirements

## Mandatory matrix design principle

Separate local step verdict from global campaign debt.

A step must not be forced into PASS_WITH_WARNINGS only because unrelated global caps exist. Global caps must be carried in a separate matrix.

## Mandatory cost dimensions

Include at least these cost dimensions:

- LLM input context cost.
- LLM output cost.
- LLM retry/rework cost.
- Broad-read cost.
- Evidence packaging cost.
- Local hardware runtime cost.
- Local disk/network cost.
- Local organ-agent/script cost.
- Manual Owner interaction cost.
- Review cost for Logos/Inquisitor/Speculum.
- Throne bundle production/retrieval cost.

## Mandatory KPD dimensions

KPD must include:

- value delivered;
- evidence strength;
- reusable Skill/validator improvement;
- context reduction;
- output reduction without evidence loss;
- manual work reduction;
- reduction of future task friction;
- matrix clarity improvement.

## Fake economy rules

The following must be FAIL, not optimization:

- fewer tokens by dropping required receipts;
- shorter final answer with missing commit links;
- reduced context by ignoring required read-first files;
- no web research but claiming research complete;
- no Throne bundle when GitHub verification fails and task requires evidence;
- deleting artifacts without retention policy.
