# Web Research Requirements

Perform broad and deep web research on cost reduction for LLM and agent workflows.

Research areas:

- prompt and context budget methods;
- retrieval and indexing strategies;
- prompt caching and reuse patterns;
- context compression and summarization policies;
- output bloat reduction without evidence loss;
- agent workflow cost control;
- local tooling for token/count estimation;
- model routing and cheap-model triage patterns;
- validation before expensive reasoning;
- artifact retention and cleanup policies;
- batch vs incremental workflows;
- parallel review cost reduction;
- CLI automation cost discipline.

For each source, record:

- title;
- URL;
- source type;
- date accessed;
- trust level;
- key idea;
- possible IMPERIUM application;
- risk or limitation.

Do not copy long copyrighted material. Summarize and cite source URLs inside the research dossier.

Create:

- `web_research_sources.json`
- `web_research_summary.md`
- `web_research_dossier.zip`
