# Servitor Final Response Contract

For every non-BLOCK task, final chat response must contain only:

1. Step name
2. Step verdict
3. Commit links list with short labels explaining what each commit carries
4. Exactly 3-4 short Russian Owner-facing comment lines

All detailed evidence belongs in repo reports and bundles.

If the task is BLOCK, provide:
- Step name
- BLOCK verdict
- exact blocker evidence
- required Owner options
